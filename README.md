# Bore Match: ballistics calculator

Match rifle powder burn rate and barrel length to the case and the bore. Not a load recipe.

A static, client-side React + Vite app. Everything runs in the browser; there is no server.

- Live: https://askdangerousquestions.github.io/ballistics-calculator/
- Test: https://askdangerousquestions.github.io/ballistics-calculator-test/

See [WORKFLOW.md](WORKFLOW.md) for how changes go from the test site to the live site.
